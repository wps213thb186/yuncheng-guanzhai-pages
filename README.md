# 运乘观宅 V1 设计版

版本：1.3-design；范围仅为运乘观宅，不含学院。

## 打开方式

当前本机入口：http://127.0.0.1:8769/index.html
全部页面导览：http://127.0.0.1:8769/app.html#guide

关闭预览后，双击「启动预览.command」，按窗口显示的地址打开。需要系统 Python 3，3D 所需 Three.js 0.184.0 已随包附带；不需要外部 CDN。不能直接双击 HTML 运行模块。

## 已完成范围

首页罗盘空间动画 → 图片预览 → 北向与门主灶手工确认 → 演示订单 → 完整报告 → 我的报告回看。

报告包含总览、门主灶、八宫、气路、依据五个页签；附体验登录、空态、图片校验、支付失败、未知方向、人工复核清单。

北向未知或取点不满足条件时不输出确定房间关系。固定 3D 与四态气路仅用于内置样例；自选图片或改变样例位置、方向后使用对应平面，避免模型与输入错配。

## 版本保护

这是新目录，不覆盖原 Beta 或之前 full Demo。浏览器记录使用独立 yc-guanzhai-v1-* 命名空间，不迁移、不删除旧记录。重复演示付款复用同份报告；实际输入改变后可新建。

原图只留在本机会话，不写入持久报告记录；刷新后自选图片不可回看，确认信息和文字结果仍可回看。

## 验证

原 full 主流程已在浏览器走通；V1 针对幂等、输入变更、删除记录再支付作了检查。方向转换、未知方向、中宫、固定模型隔离、快照读取等 12 项核心检查通过。两个子代理分别完成流程和移动端必要收尾。

V1 首页及报告进行最新安全截图验收；3D 核心文件按原先固定 SHA-384 校验值核验后本地化，附 MIT 授权。文件清单见 FILES.sha256。

## 首页版式（2026-10-18）

首页为翻页式（一屏一个主张）：`index.html` + `home-deck.css`；桌面左文右 3D，窄屏 3D 在上、内容在下。`home-full.css`、`home-record.css` 已移入 `internal/legacy/`。

- 滚动到哪一屏，通过点击隐藏的 `.story-steps` 按钮切换 3D 演示步骤（`?screen=N` 可直接深链到第 N 屏）。
- 3D 场景的 DOM 钩子（`#scene-status`、`#fallback`、`#reading-*` 等）保持不变，`spatial/compass-v4.js` 仅新增无 3D 时给 `.hero-scene` 加 `no-3d` 类。
- 设计背景见项目根 `docs/设计立场-勘宅记录-20261018.md`（含方向修正）。

## 首页与 3D 的耦合点（2026-10-18）

- 翻屏通过点击隐藏的 `.story-steps` 按钮切换 3D 步骤（0 平面 / 1 布宫 / 2 门主灶 / 3 气路）。
- `spatial/compass-v4.js` 暴露 `window.YC_HOME`：`decor(show)` 控制罗盘与九宫层、`marks(show)` 控制 3D 门主灶点位、`mode("marks")` 隐藏 DOM 卡片、`jump(n)` 无过渡切步骤、`setStatus(text)` 覆盖状态文案。
- 注意：不要用外部代码直接改 `stage._camera` 位置来拉近镜头——实测会让画面空白（相机进入模型/被裁剪），如需改视角应在 `changeStep` 里统一调。
